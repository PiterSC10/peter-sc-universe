# PETER SC® — Universo Digital

Web personal de Pedro Soriano Calderón. Diseño editorial amarillo/negro, mosaico interactivo y currículum.

## Contenido

- `index.html`: página principal.
- `style.css`: diseño, animación y adaptación a móvil.
- `app.js`: filtros y ventanas emergentes.
- `cv.html`: currículum imprimible.
- `assets/`: avatar ilustrativo y favicon en SVG.
- `.nojekyll`: permite publicar los archivos estáticos con GitHub Pages.

## Publicación en GitHub Pages

1. Crear un repositorio público llamado `peter-sc-universe`.
2. Subir **el contenido descomprimido de esta carpeta** a la raíz del repositorio, rama `main` (no subir solo el ZIP).
3. En **Settings → Pages**, seleccionar **Deploy from a branch** y elegir `main` y `/(root)`. Guardar.
4. La dirección prevista será `https://pitersc10.github.io/peter-sc-universe/` una vez que GitHub confirme la publicación.

## Actualización

Para cambiar los proyectos y enlaces, editar el objeto `projects` de `app.js`. Para cambiar estilos, editar `style.css`. `cv.html` tiene su propia hoja de estilos.

No requiere claves, servidor, base de datos ni instalación de paquetes. Los enlaces a herramientas de gestión y otras áreas privadas deben permanecer fuera del sitio público.

**Aviso:** El avatar es una ilustración temporal, no el avatar AVO oficial. Algunos perfiles tienen enlaces de búsqueda hasta que se confirmen sus enlaces directos. Datos y experiencia del CV deben revisarse antes de uso profesional.
